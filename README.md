# M3U Playlist Category Cleaner
[![Ko-fi](https://img.shields.io/badge/Support%20on-Ko--fi-FF5E5B?style=for-the-badge&logo=ko-fi&logoColor=white)](https://ko-fi.com/gamerec)

A fast, lightweight, and clean desktop utility written in Python (Tkinter) designed to parse, organize, filter, and clean large M3U/M3U8 IPTV playlist files.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## Features

- **Zero Bloat & Dependencies:** Runs entirely on Python's standard library (`tkinter`, `re`, `os`). No heavy external frameworks required.
- **Smart Grouping & Tabs:** Automatically separates playlist categories into intuitive tabs (**Live TV**, **Movies**, **Series**, **Other**) and groups them by country or region (e.g., Sweden, Iceland, Poland) and attributes like 4K or 24/7.
- **Collapsible Tree View:** Easily expand or collapse category groups with a single click (`+` / `-`).
- **Live Selection Counters:** Real-time tracking of selected categories and individual channels vs total counts.
- **Bilingual Interface:** Instant switching between English (default) and Polish (`PL` / `EN`).
- **Modern Clean UI:** Custom borderless window design with smooth mousewheel scrolling support.
